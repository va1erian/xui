# xui-core

The backend-agnostic core of [xui](../xui): pixel geometry, typed length units,
colour, the pure layout arithmetic, the semantic theme tokens, the input
vocabulary and the accessibility tree model.

It has no platform dependency and no `unsafe`, so every backend shares these
types. See the [workspace README](../../README.md) and the
[epic](https://github.com/va1erian/xui/issues/1).
