# xui

Cross-platform UI for Rust: small, fast, idiomatic and properly themed.

`xui` is the umbrella crate. It selects a backend by feature (`win32` by
default) and re-exports the shared front layer from [xui-core](../xui-core).

See the [workspace README](../../README.md) and the
[epic](https://github.com/va1erian/xui/issues/1) for the roadmap.
